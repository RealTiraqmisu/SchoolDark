---------

**ตารางที่ 3.2 UC-ADM-02 พิจารณาเอกสารผู้สมัคร**

|                               |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |               |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| **Use Case Name**             | พิจารณาเอกสารผู้สมัคร                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | ID: UC-ADM-02 |
| **Brief Description**         | เจ้าหน้าที่ทะเบียนตรวจสอบความครบถ้วนและความถูกต้องของเอกสารหลักฐานที่ผู้สมัครแนบมา พร้อมบันทึกผลการพิจารณาเพื่อใช้เป็นเงื่อนไขในการอนุมัติสิทธิ์เข้าสอบและแจ้งเตือนผู้ปกครอง                                                                                                                                                                                                                                                                                                                                                                                                                      |               |
| **Actor(s)**                  | ผู้ดูแลระบบ, เจ้าหน้าที่ทะเบียน (Primary)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |               |
| **Stakeholders**              | ผู้สมัคร, ผู้ปกครอง, คณะกรรมการรับนักเรียน, นายทะเบียน                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |               |
| **Pre-Conditions**            | 1. เจ้าหน้าที่ทะเบียนเข้าสู่ระบบด้วยสิทธิ์ที่เหมาะสม<br><br>2. มีรายการผู้สมัครที่แนบเอกสารหลักฐานเรียบร้อยแล้วในระบบ<br><br>3. มีการกำหนดรายการเอกสารที่ต้องใช้ไว้ล่วงหน้า                                                                                                                                                                                                                                                                                                                                                                                                                       |               |
| **Post-Conditions**           | 1. ผลการพิจารณาเอกสารของผู้สมัคร (ครบถ้วนหรือไม่ครบถ้วน) ถูกบันทึกลงสู่ระบบ<br><br>2. สถานะเอกสารในหน้ารายการผู้สมัครและหน้ารายละเอียดผู้สมัครได้รับการอัปเดตให้สอดคล้องกันทันที<br><br>3. ผู้สมัครที่เอกสารไม่ครบถูกรวมเป็นกลุ่มเป้าหมายสำหรับการแจ้งเตือน                                                                                                                                                                                                                                                                                                                                       |               |
| **Basic Flow of Events**      | 1. เจ้าหน้าที่ทะเบียนเปิดรายการผู้สมัครในขั้นตอนแรกของกระบวนการคัดเลือก<br><br>2. ระบบแสดงสถานะความครบถ้วนของเอกสารของผู้สมัครแต่ละราย<br><br>3. เจ้าหน้าที่ทะเบียนเลือกดูเอกสารที่แนบมาของผู้สมัครรายหนึ่ง<br><br>4. ระบบแสดงรายการเอกสารที่ผู้สมัครแนบไว้พร้อมสถานะการอัปโหลดของแต่ละรายการ<br><br>5. เจ้าหน้าที่ทะเบียนตรวจสอบเอกสารแต่ละรายการ<br><br>6. เจ้าหน้าที่ทะเบียนบันทึกผลการพิจารณาว่าเอกสารครบถ้วนหรือไม่ พร้อมระบุรายการที่ขาด<br><br>7. ระบบบันทึกผล และปรับสถานะเอกสารที่แสดงในรายการผู้สมัครและรายละเอียดผู้สมัคร                                                              |               |
| **Alternate/Exception Flows** | **Alt Flow 6a พิจารณาเอกสารหลายรายพร้อมกัน**<br><br>1. เจ้าหน้าที่ทะเบียนเลือกผู้สมัครหลายรายพร้อมกัน<br><br>2. เจ้าหน้าที่ทะเบียนบันทึกผลการพิจารณาเอกสารให้กับกลุ่มผู้สมัครที่เลือก<br><br>3. ระบบบันทึกผลและปรับสถานะเอกสารของผู้สมัครทุกรายในกลุ่ม<br><br>**Alt Flow 7a แจ้งผู้ปกครองให้ส่งเอกสารเพิ่ม**<br><br>1. หลังบันทึกผลว่าเอกสารไม่ครบถ้วน เจ้าหน้าที่ทะเบียนเลือกกลุ่มผู้สมัครดังกล่าว<br><br>2. เจ้าหน้าที่ทะเบียนส่งอีเมลแจ้งเตือนการส่งเอกสารเพิ่มเติมไปยังผู้ปกครอง<br><br>**Exception 3a ไม่พบข้อมูลผู้สมัคร**<br><br>1. ระบบแจ้งว่าไม่พบผู้สมัครรายนั้น และไม่แสดงรายการเอกสาร |               |

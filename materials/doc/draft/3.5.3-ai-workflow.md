### 3.5.3 ลำดับการทำงานร่วมกับ AI

คณะผู้จัดทำใช้ AI ช่วยงานตั้งแต่ขั้นวิเคราะห์ความต้องการจนถึงขั้นออกแบบ โดยแบ่งหน้าที่ให้ AI เป็นผู้ร่างเอกสาร และให้คณะผู้จัดทำเป็นผู้ตรวจและอนุมัติทุกครั้งก่อนนำไปใช้ในขั้นถัดไป ลำดับการทำงานแสดงดังรูปที่ 3.X ซึ่งแบ่งเป็น 2 เลน คือ คณะผู้จัดทำ และ AI เรียงตามเวลาจากซ้ายไปขวา

**รอบที่ 1**

- คณะผู้จัดทำทำ user journey ของระบบ แล้วบอกหน้าตาที่ต้องการด้วย prompt (บางครั้งวาด simple wireframe ประกอบ) เพื่อให้ AI ทำ wireframe เป็น HTML แบบโต้ตอบได้ทั้งหมด
- AI กลั่นความต้องการเชิงฟังก์ชันและไม่เป็นฟังก์ชัน (FR/NFR) และ use case จากหน้าเว็บที่ทำไว้ และร่างฐานข้อมูลเบื้องต้น
- คณะผู้จัดทำนำผลไปส่งรายงานความคืบหน้า

**จุดเปลี่ยน**

หลังส่งรายงานความคืบหน้า คณะผู้จัดทำพบว่า requirement ส่วนที่ต้องเชื่อมกับระบบของกลุ่มอื่นยังไม่ครบ เพราะรอบแรกอ้างอิงจากหน้าเว็บเป็นหลัก คณะผู้จัดทำจึงเติม requirement ส่วนนั้นให้ชัดขึ้น และทบทวนเอกสารวิเคราะห์ใหม่ทั้งชุด โดยเริ่มจากให้ AI ซักถามขอบเขตงานทีละประเด็นด้วย Skill `/grill-with-docs` ผลคือเอกสารรอบที่ 2 ครอบคลุมงานที่ไม่มีหน้าเว็บ และระบุจุดเชื่อมกับกลุ่มอื่นได้ชัดเจนขึ้น

**ขั้นวิเคราะห์ (Analysis) รอบที่ 2**

- AI ซักถามขอบเขตงานด้วย `/grill-with-docs` คณะผู้จัดทำเป็นผู้ตอบ
- AI ร่าง FR/NFR คณะผู้จัดทำตรวจและอนุมัติ
- คณะผู้จัดทำวาด use case diagram ด้วยตนเอง
- AI ร่าง use case description คณะผู้จัดทำตรวจและอนุมัติ
- AI ร่าง swimlane diagram ด้วย Skill `/diagram-design` คณะผู้จัดทำตรวจและอนุมัติ
- ไฟล์ที่ได้: FR/NFR · use case diagram · use case description · swimlane diagram

**ขั้นออกแบบ (Design)**

- คณะผู้จัดทำร่างฐานข้อมูลฉบับเต็มเป็นหลัก โดยให้ AI ช่วยตรวจ หาก AI ตรวจแล้วยังไม่ผ่าน คณะผู้จัดทำจะบอกโครงสร้างใหม่ให้ AI สร้างซ้ำ
- คณะผู้จัดทำปรับ wireframe ตาม requirement ใหม่ โดยส่วนใหญ่สั่งด้วย prompt ให้ AI ทำเป็น HTML แล้วตรวจและอนุมัติ
- คณะผู้จัดทำทำหน้าจอใน Figma ร่วมกันทั้ง 3 กลุ่ม ซึ่งอยู่ระหว่างดำเนินการ
- AI จัดทำ AI Specification ซึ่งอยู่ระหว่างดำเนินการ คณะผู้จัดทำตรวจและอนุมัติ
- ไฟล์ที่ได้: ER Diagram · wireframe แบบ HTML · final-report.md · CONTEXT.md · AGENTS.md (หน้าจอใน Figma ยังไม่เสร็จ)

ขั้นวิเคราะห์และขั้นออกแบบทำ 2 รอบ โดยรอบที่ 2 แก้ไขเอกสารจากรอบแรกตามจุดเปลี่ยนข้างต้น

**ขั้นที่เป็นแผน**

ขั้นพัฒนา ขั้นทดสอบ และขั้นนำขึ้นใช้งานจริง ยังไม่ได้ดำเนินการ ในรูปที่ 3.X จึงแสดงเป็นเส้นประ และวางแผนตามแนวคิดในหัวข้อ 2.1.2 ดังนี้

- AI เสนอ plan.md คณะผู้จัดทำอนุมัติก่อนเริ่มเขียนโค้ด
- AI เขียนโค้ดและชุดทดสอบ
- คณะผู้จัดทำตรวจ Pull Request แล้วจึงนำขึ้นใช้งานจริง

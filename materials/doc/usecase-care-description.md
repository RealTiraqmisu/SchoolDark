## 1. ข้อมูลบุคลากร

|                               |                                                                                                                                                                                                                                       |               |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| **Use Case Name**             | ดูข้อมูลบุคลากร                                                                                                                                                                                                                       | ID: UC-STF-01 |
| **Brief Description**         | ผู้ใช้ค้นหาและดูข้อมูลบุคลากรในโรงเรียน ทั้งรายชื่อและรายละเอียดรายบุคคล                                                                                                                                                              |               |
| **Actor(s)**                  | เจ้าหน้าที่บุคคล (Primary), ผู้ดูแลระบบ                                                                                                                                                                                               |               |
| **Stakeholders**              | บุคลากรในโรงเรียน, ผู้บริหารโรงเรียน                                                                                                                                                                                                  |               |
| **Pre-Conditions**            | 1. ผู้ใช้เข้าสู่ระบบด้วยสิทธิ์ที่เหมาะสม<br><br>2. มีข้อมูลบุคลากรในระบบ                                                                                                                                                                |               |
| **Post-Conditions**           | 1. ระบบแสดงข้อมูลบุคลากรที่ผู้ใช้เลือก                                                                                                                                                                                                 |               |
| **Basic Flow of Events**      | 1. ผู้ใช้เปิดเมนูข้อมูลบุคลากร<br><br>2. ระบบแสดงรายชื่อบุคลากรทั้งหมด<br><br>3. ผู้ใช้ค้นหาหรือกรองตามชื่อ ประเภทบุคลากร หรือแผนก<br><br>4. ผู้ใช้เลือกบุคลากรที่ต้องการ<br><br>5. ระบบแสดงรายละเอียด เช่น ประวัติส่วนตัว การศึกษา ตำแหน่งงาน |               |
| **Alternate/Exception Flows** | **Exception 3a ไม่พบข้อมูล**<br><br>1. ระบบแจ้งว่าไม่พบบุคลากรตามเงื่อนไขที่ค้นหา                                                                                                                                                     |               |

| **Pre-Conditions**            | 1. ผู้ใช้เข้าสู่ระบบด้วยสิทธิ์ที่เหมาะสม<br><br>2. มีการตั้งค่าประเภทบุคลากร ตำแหน่งงาน และแผนกไว้แล้ว                                                                                                                                                                  |               |

| **Basic Flow of Events**      | 1. ผู้ใช้เปิดเมนูข้อมูลบุคลากร แล้วกดเพิ่มบุคลากร<br><br>2. ระบบแสดงฟอร์มข้อมูลบุคลากร<br><br>3. ผู้ใช้กรอกข้อมูลพื้นฐาน การศึกษา และตำแหน่งงาน<br><br>4. ผู้ใช้กดบันทึก<br><br>5. ระบบตรวจสอบข้อมูลและบันทึกลงระบบ                                                          |               |
| **Alternate/Exception Flows** | **Alt Flow 1a แก้ไขข้อมูล**<br><br>1. ผู้ใช้เลือกบุคลากร แล้วกดแก้ไข<br><br>2. ผู้ใช้แก้ไขข้อมูลแล้วกดบันทึก<br><br>**Alt Flow 1b ลบข้อมูล**<br><br>1. ผู้ใช้เลือกบุคลากร แล้วกดลบ<br><br>2. ระบบให้ยืนยันก่อนลบ แล้วลบข้อมูล<br><br>**Alt Flow 1c นำเข้าจาก Excel**<br><br>1. ผู้ใช้อัปโหลดไฟล์ Excel<br><br>2. ระบบแสดงตัวอย่างข้อมูล ผู้ใช้ยืนยันแล้วระบบบันทึก<br><br>**Exception 5a ข้อมูลไม่ครบหรือซ้ำ**<br><br>1. ระบบแจ้งช่องที่ผิด และยังไม่บันทึก |               |

| **Alternate/Exception Flows** | **Exception 3a ข้อมูลไม่ครบ**<br><br>1. ระบบแจ้งหัวข้อที่ยังไม่มีข้อมูล ผู้ใช้เลือกพิมพ์ต่อหรือกลับไปแก้ไขข้อมูลก่อน                                                                                                                     |               |

## 2. การลาของบุคลากร

**ตารางที่ 3.x UC-SLV-01 เพิ่ม ลบ แก้ไขคำขอลาของตนเอง**

|                               |                                                                                                                                                                                                                                                                                                       |               |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| **Use Case Name**             | เพิ่ม ลบ แก้ไขคำขอลาของตนเอง                                                                                                                                                                                                                                                                          | ID: UC-SLV-01 |
| **Brief Description**         | ครูหรือบุคลากรยื่นคำขอลา และแก้ไขหรือลบคำขอที่ยังไม่ถูกพิจารณา                                                                                                                                                                                                                                         |               |
| **Actor(s)**                  | ครู / บุคลากร (Primary)                                                                                                                                                                                                                                                                               |               |
| **Stakeholders**              | ผู้อนุมัติการลาบุคลากร, เจ้าหน้าที่บุคคล                                                                                                                                                                                                                                                              |               |
| **Pre-Conditions**            | 1. ผู้ใช้เข้าสู่ระบบแล้ว<br><br>2. มีการตั้งค่าระบบการลาบุคลากร ในส่วนประเภทการลา โควตา และผู้อนุมัติไว้แล้ว                                                                                                                                                                                                     |               |
| **Post-Conditions**           | 1. คำขอลาถูกบันทึกด้วยสถานะ "รอตรวจสอบ"<br><br>2. ผู้อนุมัติเห็นคำขอในรายการที่ต้องพิจารณา                                                                                                                                                                                                              |               |
| **Basic Flow of Events**      | 1. ผู้ใช้เปิดเมนูการลา แล้วกดยื่นคำขอลา<br><br>2. ผู้ใช้เลือกประเภทการลา ช่วงวันที่ (เต็มวัน/ครึ่งวัน) และกรอกเหตุผล<br><br>3. ผู้ใช้แนบเอกสาร (ถ้ามี)<br><br>4. ระบบตรวจสอบโควตาคงเหลือและจำนวนวันที่ต้องแจ้งล่วงหน้า<br><br>5. ผู้ใช้กดส่งคำขอ<br><br>6. ระบบบันทึกคำขอด้วยสถานะ "รอตรวจสอบ"                                 |               |
| **Alternate/Exception Flows** | **Alt Flow 1a แก้ไขหรือลบคำขอ**<br><br>1. ผู้ใช้เลือกคำขอที่สถานะยังเป็น "รอตรวจสอบ"<br><br>2. ผู้ใช้แก้ไขแล้วบันทึก หรือกดลบแล้วยืนยัน<br><br>**Exception 4a โควตาไม่พอ**<br><br>1. ระบบแจ้งว่าโควตาคงเหลือไม่พอ และไม่ให้ส่งคำขอ<br><br>**Exception 4b แจ้งล่วงหน้าไม่ทัน**<br><br>1. ระบบแจ้งจำนวนวันที่ต้องแจ้งล่วงหน้า และไม่ให้ส่งคำขอ<br><br>**Exception 1a.1 คำขอถูกพิจารณาแล้ว**<br><br>1. ระบบไม่แสดงปุ่มแก้ไขและลบ |               |

| **Brief Description**         | ครูหรือบุคลากรติดตามสถานะคำขอลา ดูประวัติการลา และโควตาวันลาคงเหลือของตนเอง                                                                                                                         |               |
| **Actor(s)**                  | ครู / บุคลากร (Primary)                                                                                                                                                                           |               |

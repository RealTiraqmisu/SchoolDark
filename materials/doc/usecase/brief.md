**รายละเอียด Use Case โดยสังเขป**

  Use Case ID Use Case Name              Actor              Description (ชื่อภาษาไทย)

  UC-ADM-01   จัดการข้อมูลผู้สมัคร             เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่งานทะเบียนค้นหา เพิ่ม แก้ไข และลบข้อมูลผู้สมัครเรียน
                                                            เพื่อใช้ในกระบวนการรับสมัครนักเรียน

  UC-ADM-02   พิจารณาเอกสารผู้สมัคร          เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่ตรวจเอกสารที่ผู้สมัครอัปโหลด
                                                            และระบุผลตรวจผ่าน/ไม่ผ่านของแต่ละเอกสารเพื่อประกอบการพิจารณา

  UC-ADM-03   จัดการสถานะผู้สมัคร            เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่เปลี่ยนสถานะใบสมัครตามขั้นตอนของรอบรับสมัคร จนถึงการรับเป็นนักเรียนหรือปฏิเสธ

  UC-ADM-04   ส่งอีเมลถึงผู้สมัคร              เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่เลือกผู้สมัครแล้วส่งอีเมลเป็นเทมเพลตที่ตั้งไว้ เช่น แจ้งผลพิจารณาหรือเอกสารที่ต้องเพิ่มเติม

  UC-ADM-05   ส่งออกใบสมัคร                เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่พิมพ์หรือส่งออกใบสมัครรายบุคคลหรือชุดตามเงื่อนไข เพื่อจัดเก็บหรือใช้ดำเนินการต่อ

  UC-ADM-06   สมัครเรียน                   ผู้สมัครเรียน          ผู้สมัครกรอกฟอร์มออนไลน์ อัปโหลดเอกสารที่กำหนด และยืนยันตัวตนด้วย OTP เพื่อยื่นใบสมัครเข้ารอบ
                                                            ที่เปิดรับอยู่

  UC-REG-01   จัดการข้อมูลนักเรียนและศิษย์เก่า   เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่ค้นหา เพิ่ม แก้ไขข้อมูลนักเรียนปัจจุบันและศิษย์เก่า
                                                            ให้เป็นแหล่งข้อมูลทะเบียนกลางของโรงเรียน

  UC-REG-02   เพิ่มข้อมูลนักเรียน              เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่เพิ่มข้อมูลนักเรียนใหม่เข้าระบบ สำหรับนักเรียนย้ายเข้าหรือที่ไม่ได้มาจากการมอบตัวในระบบ

  UC-REG-03   แก้ไขข้อมูลนักเรียน             ครูประจำชั้น          ครูประจำชั้นแก้ไขข้อมูลนักเรียนในห้องตนเองเพื่อให้ข้อมูลทะเบียนเป็นปัจจุบัน (ข้อกำหนด:
                                                            เฉพาะห้องตนเอง)

  UC-REG-04   ย้ายห้องเรียน เลื่อนชั้นนักเรียน    เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่ปิดประวัติห้องเดิมแล้วสร้างประวัติห้องใหม่ เมื่อนักเรียนเลื่อนชั้นหรือย้ายห้องเรียน

  UC-REG-05   จัดการนักเรียนลาออก           เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่บันทึกการลาออกหรือย้ายออกของนักเรียน และปรับสถานะนักเรียนในระบบให้ถูกต้อง

  UC-REG-06   ดูข้อมูลนักเรียนและศิษย์เก่า       ครู,                ครูและเจ้าหน้าที่ค้นดูข้อมูลนักเรียนและศิษย์เก่าเพื่อสืบค้นข้อมูลโดยไม่แก้ไข
                                         เจ้าหน้าที่งานทะเบียน   

  UC-REG-07   ส่งออกรายชื่อนักเรียน           ครู,                ครูและเจ้าหน้าที่กำหนดเงื่อนไขแล้วส่งออกรายชื่อนักเรียนเป็นไฟล์เพื่อนำไปใช้งานต่อ
                                         เจ้าหน้าที่งานทะเบียน   

  UC-REG-08   ส่งออกรายงานและสถิติ          ครู,                ครูและเจ้าหน้าที่ส่งออกรายงานและสถิติ เช่น จำนวนนักเรียนรายชั้น ตามเงื่อนไขที่เลือก
                                         เจ้าหน้าที่งานทะเบียน   

  UC-REG-09   ส่งออก ปพ.1 และ 2           เจ้าหน้าที่งานทะเบียน   เจ้าหน้าที่ส่งออกเอกสาร ปพ.1 และ ปพ.2 ของนักเรียนจากข้อมูลในทะเบียน

  UC-SET-01   ตั้งค่าข้อมูลระบบโรงเรียน        ผู้ดูแลระบบ           ผู้ดูแลระบบจัดการข้อมูลพื้นฐานของโรงเรียน เช่น ชื่อ รหัส ที่ตั้ง และช่วงชั้น/ปีการศึกษาที่เปิดใช้งาน

  UC-SET-02   ตั้งค่างานบุคลากร              ผู้ดูแลระบบ,          ผู้ดูแลระบบและหัวหน้างานบุคคลกำหนดค่าตั้งต้นของงานฝ่ายบุคคล เช่น ประเภทบุคลากร ตำแหน่ง
                                         หัวหน้างานบุคคล       และแผนก

  UC-SET-03   ตั้งค่างานทะเบียนนักเรียน        หัวหน้างานทะเบียน     หัวหน้างานทะเบียนกำหนดเงื่อนไขของงานทะเบียน เช่น
                                                            รูปแบบรหัสนักเรียนและคอลัมน์ที่ใช้แสดงในตาราง

  UC-SET-04   ตั้งค่างานรับสมัครนักเรียน        หัวหน้างานทะเบียน     หัวหน้างานทะเบียนกำหนดค่าตั้งต้นของงานรับสมัคร เช่น ฟอร์มสมัคร เอกสาร
                                                            และแผนการเรียนที่เปิดรับ

  UC-STF-01   ดูข้อมูลบุคลากร                เจ้าหน้าที่งานบุคคล     เจ้าหน้าที่งานบุคคลค้นหาและดูข้อมูลบุคลากรในโรงเรียน ทั้งรายชื่อและรายละเอียดรายบุคคล

  UC-STF-02   เพิ่ม แก้ไข ลบข้อมูลบุคลากร      เจ้าหน้าที่งานบุคคล     เจ้าหน้าที่งานบุคคลเพิ่มบุคลากรใหม่ แก้ไขข้อมูลเดิม และลบบุคลากรที่ไม่อยู่แล้ว รวมถึงนำเข้าข้อมูล

  UC-STF-03   พิมพ์แฟ้มประวัติประจำตัวบุคลากร   เจ้าหน้าที่งานบุคคล     เจ้าหน้าที่งานบุคคลพิมพ์แฟ้มประวัติประจำตัวบุคลากรตามแบบฟอร์มที่กำหนดเพื่อใช้เป็นเอกสารอ้างอิง

**ตารางที่ ก.1 UC-ADM-01 จัดการข้อมูลผู้สมัคร**

+-------------------------------+----------------------------------------------------------+----------------------------------------------------------+
| **Use Case Name**             | จัดการข้อมูลผู้สมัคร                                           | ID: UC-ADM-01                                            |
+===============================+==========================================================+==========================================================+
| **Brief Description**         | เจ้าหน้าที่งานทะเบียนสามารถค้นหา เรียกดูรายละเอียด เพิ่ม แก้ไข และลบข้อมูลผู้สมัครเรียนที่ยื่นเข้ามาในระบบ เพื่อใช้ในกระบวนการรับสมัครนักเรียน    |
+-------------------------------+---------------------------------------------------------------------------------------------------------------------+
| **Actor(s)**                  | เจ้าหน้าที่งานทะเบียน (Primary)                                                                                          |
+-------------------------------+---------------------------------------------------------------------------------------------------------------------+
| **Stakeholders**              | ผู้สมัคร, ผู้ปกครอง, คณะกรรมการรับนักเรียน, นายทะเบียน                                                                       |
+-------------------------------+---------------------------------------------------------------------------------------------------------------------+
| **Pre-Conditions**            | 1\. เจ้าหน้าที่งานทะเบียนเข้าสู่ระบบด้วยสิทธิ์ที่เหมาะสม                                                                          |
|                               |                                                                                                                     |
|                               | 2\. มีรอบรับสมัครที่เปิดใช้งานอยู่ และมีข้อมูลผู้สมัครอยู่ในระบบอย่างน้อย 1 ราย                                                        |
+-------------------------------+---------------------------------------------------------------------------------------------------------------------+
| **Post-Conditions**           | 1\. ข้อมูลผู้สมัครที่ค้นหาแสดงผลถูกต้องตรงตามเงื่อนไขที่ระบุ                                                                       |
|                               |                                                                                                                     |
|                               | 2\. ข้อมูลที่แก้ไขถูกบันทึกพร้อมประวัติผู้แก้ไขและเวลาที่แก้ไข                                                                       |
|                               |                                                                                                                     |
|                               | 3\. ข้อมูลที่ถูกลบจะไม่ปรากฏในระบบอีกต่อไป และไม่สามารถกู้คืนได้                                                                 |
+-------------------------------+---------------------------------------------------------------------------------------------------------------------+
| **Basic Flow of Events**      | 1\. เจ้าหน้าที่งานทะเบียนเข้าสู่หน้ารายการผู้สมัคร                                                                              |
|                               |                                                                                                                     |
|                               | 2\. ระบบแสดงรายการผู้สมัครแยกตามขั้นตอนของกระบวนการรับสมัครนักเรียน                                                          |
|                               |                                                                                                                     |
|                               | 3\. เจ้าหน้าที่งานทะเบียนค้นหาหรือกรองรายการตามชื่อ รหัสผู้สมัคร ระดับชั้น หรือแผนการเรียน                                            |
|                               |                                                                                                                     |
|                               | 4\. เจ้าหน้าที่งานทะเบียนเลือกผู้สมัครที่ต้องการดูรายละเอียด                                                                      |
|                               |                                                                                                                     |
|                               | 5\. ระบบแสดงประวัติและความคืบหน้าของผู้สมัครรายนั้น                                                                          |
|                               |                                                                                                                     |
|                               | 6\. เจ้าหน้าที่งานทะเบียนเลือกแก้ไขข้อมูลและระบุข้อมูลที่ต้องการปรับปรุง                                                             |
|                               |                                                                                                                     |
|                               | 7\. ระบบตรวจสอบความถูกต้องของข้อมูล บันทึกการเปลี่ยนแปลง พร้อมบันทึกผู้แก้ไขและเวลาที่แก้ไข                                          |
+-------------------------------+---------------------------------------------------------------------------------------------------------------------+
| **Alternate/Exception Flows** | **Alt Flow 6a ลบข้อมูลผู้สมัคร**                                                                                         |
|                               |                                                                                                                     |
|                               | 1\. เจ้าหน้าที่งานทะเบียนเลือกลบข้อมูลผู้สมัครแทนการแก้ไข                                                                       |
|                               |                                                                                                                     |
|                               | 2\. ระบบแสดงข้อความยืนยันการลบข้อมูลและแจ้งเตือนว่าไม่สามารถกู้คืนได้                                                            |
|                               |                                                                                                                     |
|                               | 3\. เจ้าหน้าที่งานทะเบียนยืนยันการลบข้อมูล                                                                                   |
|                               |                                                                                                                     |
|                               | 4\. ระบบลบข้อมูลออกจากระบบพร้อมบันทึกประวัติการดำเนินการ                                                                    |
|                               |                                                                                                                     |
|                               | **Exception 3a ไม่พบข้อมูลตามเงื่อนไข**                                                                                  |
|                               |                                                                                                                     |
|                               | ระบบแจ้งว่าไม่พบผู้สมัครที่ตรงกับเงื่อนไขการค้นหา และแนะนำให้ปรับเงื่อนไขใหม่                                                        |
|                               |                                                                                                                     |
|                               | **Exception 7a ข้อมูลที่จำเป็นไม่ครบถ้วน**                                                                                 |
|                               |                                                                                                                     |
|                               | ระบบแจ้งเตือนว่ายังกรอกข้อมูลบังคับไม่ครบถ้วน และจะไม่บันทึกข้อมูลจนกว่าจะได้รับการแก้ไขให้ถูกต้อง                                        |
+-------------------------------+---------------------------------------------------------------------------------------------------------------------+

**ตารางที่ ก.2 UC-ADM-02 พิจารณาเอกสารผู้สมัคร**

+-------------------------------+-----------------------------------------------------------------------+-----------------------------------------------------------------------+
| **Use Case Name**             | พิจารณาเอกสารผู้สมัคร                                                     | ID: UC-ADM-02                                                         |
+===============================+=======================================================================+=======================================================================+
| **Brief Description**         | เจ้าหน้าที่ทะเบียนตรวจสอบความครบถ้วนและความถูกต้องของเอกสารหลักฐานที่ผู้สมัครแนบมา พร้อมบันทึกผลการพิจารณาเพื่อใช้เป็นเงื่อนไขในการอนุมัติสิทธิ์เข้าสอบและแจ้งเตือนผู้ปกครอง     |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------+
| **Actor(s)**                  | ผู้ดูแลระบบ, เจ้าหน้าที่ทะเบียน (Primary)                                                                                                             |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------+
| **Stakeholders**              | ผู้สมัคร, ผู้ปกครอง, คณะกรรมการรับนักเรียน, นายทะเบียน                                                                                                 |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------+
| **Pre-Conditions**            | 1\. เจ้าหน้าที่ทะเบียนเข้าสู่ระบบด้วยสิทธิ์ที่เหมาะสม                                                                                                       |
|                               |                                                                                                                                               |
|                               | 2\. มีรายการผู้สมัครที่แนบเอกสารหลักฐานเรียบร้อยแล้วในระบบ                                                                                              |
|                               |                                                                                                                                               |
|                               | 3\. มีการกำหนดรายการเอกสารที่ต้องใช้ไว้ล่วงหน้า                                                                                                       |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------+
| **Post-Conditions**           | 1\. ผลการพิจารณาเอกสารของผู้สมัคร (ครบถ้วนหรือไม่ครบถ้วน) ถูกบันทึกลงสู่ระบบ                                                                               |
|                               |                                                                                                                                               |
|                               | 2\. สถานะเอกสารในหน้ารายการผู้สมัครและหน้ารายละเอียดผู้สมัครได้รับการอัปเดตให้สอดคล้องกันทันที                                                                 |
|                               |                                                                                                                                               |
|                               | 3\. ผู้สมัครที่เอกสารไม่ครบถูกรวมเป็นกลุ่มเป้าหมายสำหรับการแจ้งเตือน                                                                                        |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------+
| **Basic Flow of Events**      | 1\. เจ้าหน้าที่ทะเบียนเปิดรายการผู้สมัครในขั้นตอนแรกของกระบวนการคัดเลือก                                                                                   |
|                               |                                                                                                                                               |
|                               | 2\. ระบบแสดงสถานะความครบถ้วนของเอกสารของผู้สมัครแต่ละราย                                                                                           |
|                               |                                                                                                                                               |
|                               | 3\. เจ้าหน้าที่ทะเบียนเลือกดูเอกสารที่แนบมาของผู้สมัครรายหนึ่ง                                                                                              |
|                               |                                                                                                                                               |
|                               | 4\. ระบบแสดงรายการเอกสารที่ผู้สมัครแนบไว้พร้อมสถานะการอัปโหลดของแต่ละรายการ                                                                            |
|                               |                                                                                                                                               |
|                               | 5\. เจ้าหน้าที่ทะเบียนตรวจสอบเอกสารแต่ละรายการ                                                                                                      |
|                               |                                                                                                                                               |
|                               | 6\. เจ้าหน้าที่ทะเบียนบันทึกผลการพิจารณาว่าเอกสารครบถ้วนหรือไม่ พร้อมระบุรายการที่ขาด                                                                         |
|                               |                                                                                                                                               |
|                               | 7\. ระบบบันทึกผล และปรับสถานะเอกสารที่แสดงในรายการผู้สมัครและรายละเอียดผู้สมัคร                                                                           |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------+
| **Alternate/Exception Flows** | **Alt Flow 6a พิจารณาเอกสารหลายรายพร้อมกัน**                                                                                                     |
|                               |                                                                                                                                               |
|                               | 1\. เจ้าหน้าที่ทะเบียนเลือกผู้สมัครหลายรายพร้อมกัน                                                                                                       |
|                               |                                                                                                                                               |
|                               | 2\. เจ้าหน้าที่ทะเบียนบันทึกผลการพิจารณาเอกสารให้กับกลุ่มผู้สมัครที่เลือก                                                                                       |
|                               |                                                                                                                                               |
|                               | 3\. ระบบบันทึกผลและปรับสถานะเอกสารของผู้สมัครทุกรายในกลุ่ม                                                                                             |
|                               |                                                                                                                                               |
|                               | **Alt Flow 7a แจ้งผู้ปกครองให้ส่งเอกสารเพิ่ม**                                                                                                       |
|                               |                                                                                                                                               |
|                               | 1\. หลังบันทึกผลว่าเอกสารไม่ครบถ้วน เจ้าหน้าที่ทะเบียนเลือกกลุ่มผู้สมัครดังกล่าว                                                                                 |
|                               |                                                                                                                                               |
|                               | 2\. เจ้าหน้าที่ทะเบียนส่งอีเมลแจ้งเตือนการส่งเอกสารเพิ่มเติมไปยังผู้ปกครอง                                                                                    |
|                               |                                                                                                                                               |
|                               | **Exception 3a ไม่พบข้อมูลผู้สมัคร**                                                                                                                |
|                               |                                                                                                                                               |
|                               | 1\. ระบบแจ้งว่าไม่พบผู้สมัครรายนั้น และไม่แสดงรายการเอกสาร                                                                                             |

**ตารางที่ ก.3 UC-ADM-03 จัดการสถานะผู้สมัคร**

+-------------------------------+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------+
| **Use Case Name**             | จัดการสถานะผู้สมัคร                                                                | ID: UC-ADM-03                                                                  |
+===============================+================================================================================+================================================================================+
| **Brief Description**         | เจ้าหน้าที่ทะเบียนปรับสถานะของผู้สมัครให้สอดคล้องกับความคืบหน้าในกระบวนการคัดเลือก ทั้งแบบรายบุคคลและแบบกลุ่ม พร้อมบันทึกคะแนนสอบ โดยมีการยืนยันก่อนดำเนินการทุกครั้งและรองรับการย้อนกลับรายการ    |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **Actor(s)**                  | ผู้ดูแลระบบ, เจ้าหน้าที่ทะเบียน (Primary)                                                                                                                               |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **Stakeholders**              | ผู้สมัคร, ผู้ปกครอง, คณะกรรมการรับนักเรียน, ฝ่ายวิชาการ, ฝ่ายการเงิน, ผู้อำนวยการโรงเรียน                                                                                      |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **Pre-Conditions**            | 1\. เจ้าหน้าที่ทะเบียนเข้าสู่ระบบด้วยสิทธิ์ที่เหมาะสม                                                                                                                         |
|                               |                                                                                                                                                                 |
|                               | 2\. มีผู้สมัครที่จะเปลี่ยนสถานะอยู่ในระบบ                                                                                                                                 |
|                               |                                                                                                                                                                 |
|                               | 3\. คณะกรรมการรับนักเรียนอนุมัติผลการคัดเลือกเรียบร้อยแล้ว (กรณีประกาศผลสอบ)                                                                                                |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **Post-Conditions**           | 1\. ผู้สมัครมีสถานะใหม่ตามที่กำหนด และถูกจัดกลุ่มตามขั้นตอนที่ตรงกับสถานะนั้นโดยอัตโนมัติ                                                                                            |
|                               |                                                                                                                                                                 |
|                               | 2\. เมื่อสถานะเปลี่ยนเป็น \"กำลังศึกษา\" หรือ \"มอบตัวเสร็จสิ้น\" ระบบจะออกรหัสนักเรียนให้อัตโนมัติตาม BR-02 และปรับเปลี่ยนสถานะผู้สมัครเข้าสู่ทะเบียนนักเรียน                                 |
|                               |                                                                                                                                                                 |
|                               | 3\. คะแนนสอบที่บันทึกปรากฏในรายละเอียดของผู้สมัครทันที                                                                                                                    |
|                               |                                                                                                                                                                 |
|                               | 4\. เจ้าหน้าที่ทะเบียนสามารถย้อนกลับการเปลี่ยนสถานะได้ทันทีหลังทำรายการ ทั้งแบบรายบุคคลและแบบกลุ่ม                                                                                |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **Basic Flow of Events**      | 1\. เจ้าหน้าที่ทะเบียนเลือกกลุ่มผู้สมัครตามขั้นตอนของกระบวนการคัดเลือกที่ต้องการดำเนินการ                                                                                          |
|                               |                                                                                                                                                                 |
|                               | 2\. ระบบแสดงรายการผู้สมัครในขั้นตอนนั้น                                                                                                                                |
|                               |                                                                                                                                                                 |
|                               | 3\. เจ้าหน้าที่ทะเบียนเลือกผู้สมัครหนึ่งรายหรือหลายรายที่ต้องการปรับสถานะ                                                                                                       |
|                               |                                                                                                                                                                 |
|                               | 4\. เจ้าหน้าที่ทะเบียนระบุสถานะใหม่ที่ต้องการเปลี่ยน                                                                                                                        |
|                               |                                                                                                                                                                 |
|                               | 5\. ระบบแสดงรายละเอียดการเปลี่ยนแปลงให้ตรวจสอบก่อนยืนยัน รวมถึงแจ้งหากผู้สมัครจะถูกย้ายไปยังขั้นตอนอื่น                                                                            |
|                               |                                                                                                                                                                 |
|                               | 6\. เจ้าหน้าที่ทะเบียนยืนยันการเปลี่ยนสถานะ                                                                                                                              |
|                               |                                                                                                                                                                 |
|                               | 7\. ระบบบันทึกสถานะใหม่ของผู้สมัครทุกรายที่เลือก แจ้งผลการดำเนินการ และแสดงตัวเลือกสำหรับการย้อนกลับรายการ                                                                       |
+-------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **Alternate/Exception Flows** | **Alt Flow 7a ย้อนกลับการเปลี่ยนสถานะ**                                                                                                                             |
|                               |                                                                                                                                                                 |
|                               | 1\. เจ้าหน้าที่ทะเบียนเลือกย้อนกลับรายการภายในระยะเวลาที่กำหนด                                                                                                            |
|                               |                                                                                                                                                                 |
|                               | 2\. ระบบคืนค่าสถานะเดิมให้กับผู้สมัครทุกรายในชุดรายการนั้น                                                                                                                  |
|                               |                                                                                                                                                                 |
|                               | **Alt Flow B บันทึกคะแนนสอบ**                                                                                                                                     |
|                               |                                                                                                                                                                 |
|                               | 1\. เจ้าหน้าที่ทะเบียนเลือกกรอกหรือแก้ไขคะแนนสอบของผู้สมัคร                                                                                                                |
|                               |                                                                                                                                                                 |
|                               | 2\. เจ้าหน้าที่ทะเบียนระบุคะแนนดิบและคะแนนเฉลี่ยสะสม                                                                                                                     |
|                               |                                                                                                                                                                 |
|                               | 3\. ระบบบันทึกคะแนนโดยไม่เปลี่ยนสถานะของผู้สมัคร                                                                                                                        |
|                               |                                                                                                                                                                 |
|                               | 4\. เจ้าหน้าที่ทะเบียนดำเนินการปรับสถานะแยกต่างหากตามผลการสอบ                                                                                                           |
|                               |                                                                                                                                                                 |
|                               | **Exception 6a ยกเลิกก่อนยืนยัน**                                                                                                                                   |
|                               |                                                                                                                                                                 |
|                               | 1\. เจ้าหน้าที่ทะเบียนยกเลิกรายการก่อนยืนยัน                                                                                                                             |
|                               |                                                                                                                                                                 |
|                               | 2\. ระบบจะไม่ทำการเปลี่ยนแปลงสถานะใด ๆ                                                                                                                             |
|                               |                                                                                                                                                                 |
|                               | **Exception B1a กรอกคะแนนไม่ครบถ้วน**                                                                                                                             |
|                               |                                                                                                                                                                 |
|                               | 1\. ระบบแจ้งเตือนว่ายังกรอกคะแนนไม่ครบถ้วน และจะไม่บันทึกข้อมูลจนกว่าจะระบุครบทุกช่อง                                                                                          |

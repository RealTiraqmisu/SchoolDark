# การแบ่ง feature ของระบบใหม่ ตามหน้า + feature ที่เพิ่มจาก school bright

ส่วนนี้ลิสต์เฉพาะสิ่งที่ลงมือทำเสร็จแล้วจริงในระบบ (เช็คกับโค้ดจริงแล้ว) — ฟีเจอร์ในลิสต์ school bright ด้านบนที่ไม่ปรากฏตรงนี้คือยังไม่ได้ทำ

## ส่วนที่เนยสดทำ

### หน้าข้อมูลนักเรียน

เป็นหน้าที่รวมรายชื่อนักเรียนทั้งระบบเข้าไว้ด้วยกัน ของเก่าไม่รู้จะแยกทำไมเยอะแยะ แล้วหน้าตาก็เหมือนกัน ก็เลยรวมศูนย์ให้ทุกอย่างอยู่หน้าข้อมูลนักเรียน แล้วจะทำอะไรก็ให้อยู่ในหน้านั้นไปเลย

หน้าข้อมูลนักเรียน ทำอะไรได้บ้าง

- ค้นหาด้วยชื่อ-นามสกุล, รหัสนักเรียน, รหัสผู้สมัคร, เลขประจำตัวประชาชน + ปุ่มรีเซ็ตตัวกรอง
- ตัวกรอง
    - ปีการศึกษา (ค้นหาได้ในตัวเลือก) และภาคเรียน (เทอม 1 / เทอม 2 / ภาคฤดูร้อน)
    - ชิปกรองระดับชั้น ม.1-ม.6
    - ชิปกรองห้องเรียน (ไล่ตามระดับชั้นที่เลือก)
    - ชิปกรองแผนการเรียน
    - ชิปกรองสถานะ พร้อมตัวเลขนับจำนวนแบบสด
- เรียงลำดับได้ 8 แบบ + สลับทิศทางน้อยไปมาก/มากไปน้อย + โหมด "อัตโนมัติ" เวลาเจาะดูรายห้อง
- แบ่งหน้า (10/25/50/100/200 รายการ) และจำค่าตัวกรอง/การเรียง/ขนาดหน้าที่ตั้งไว้ล่าสุด
- ตารางเรนเดอร์ตามค่าคอนฟิกคอลัมน์ที่ตั้งไว้ (เชื่อมกับหน้าตั้งค่า column นักเรียน)
- ทุกปุ่ม action มีป้ายบอกขอบเขตกำกับ (เช่น "N คนที่เลือก" / "N รายการตามตัวกรอง" / "ทั้งโรงเรียน" / "ยกห้อง ม.x/y") และถ้ายังทำไม่ได้จะเด้งข้อความอธิบายแทนที่จะปิดปุ่มเฉยๆ
- แถบ bulk action โผล่เมื่อติ๊กเลือกนักเรียน (ทำกับเฉพาะที่เลือกเสมอ)
- ทุกการทำรายการ (import/export/พิมพ์/ย้าย/ลบ) มีขั้นตอนพรีวิวให้ดูก่อนยืนยันเสมอ
- เพิ่มนักเรียน
    - เพิ่มนักเรียนใหม่ หรือย้ายเข้าจากสถานศึกษาอื่น
- นำเข้า/ส่งออก
    - นำเข้าข้อมูลนักเรียน & download template สำหรับใช้นำเข้าข้อมูลนักเรียน
    - ส่งออกข้อมูล (เช่น นำไปทำเป็นใบรายชื่อ) export ได้ทั้ง excel & pdf ผ่านโมดัลเดียวที่เลือกได้ครบ: ประเภทรายงาน / ขอบเขต (ตัวกรอง, ที่เลือก, เลือกห้องเอง) / คอลัมน์ที่จะ export (มี preset ให้เลือก) / รูปแบบไฟล์และรวม-แยกไฟล์
    - พิมพ์บัตรประจำตัวนักเรียน
    - ส่งข้อมูล REGIS สช. (มีทางเลือก login เข้า REGIS หรือ export เป็น excel)
- จัดการทะเบียน
    - ปพ.2
    - ปพ.1
    - เลื่อนชั้น/จบการศึกษา
    - ย้ายห้องเรียน
    - ย้ายออก/ลาออก/เปลี่ยนสถานะ
- รายงาน/สถิติ (สำหรับพิมพ์และแสดงผล)
    - รายงานระดับรายชั้น
    - export รายงานลาออก
    - export รายงานนักเรียนใหม่
- action รายคน (คลิกที่แถวนักเรียน): แก้ไขข้อมูล / ดูประวัติและคะแนน / ดูบัตรประจำตัวนักเรียน (QR) / ลบออกจากระบบ
- แผงประวัติการใช้งานระบบล่าสุด (log ว่าใครทำอะไรไปบ้าง)

### หน้าการตั้งค่า

- ตั้งค่ารับสมัคร ครบทั้ง 9 หมวด: ประวัติส่วนตัว, ที่อยู่ตามทะเบียนบ้าน, ที่อยู่ปัจจุบัน, ข้อมูลบิดา, ข้อมูลมารดา, ข้อมูลผู้ปกครอง, ข้อมูลการศึกษา, ข้อมูลสุขภาพ, หลักฐานการสมัคร — เปิด/ปิด "จำเป็นต้องระบุ" ได้รายฟิลด์ + ปุ่มบันทึก/คืนค่าเดิม
- ตั้งค่าแผนหลักสูตร → เพิ่ม/แก้ไข/ลบแผนการเรียนได้ (ระดับชั้น, ชื่อแผน, จำนวนรับ, เกณฑ์การรับสมัคร) พร้อมกำหนดการรับสมัคร 6 วันที่ (เปิดรับ, ปิดรับ, สอบ, ประกาศผล, รายงานตัว, มอบตัว) — ลบแผนแล้วลบห้องสอบที่ผูกกับแผนนั้นให้อัตโนมัติ
- ตั้งค่าห้องสอบ → ใช้จัดห้องสอบ อาจจะทั้งตอนสอบภายในและสอบ admission — ผูกกับแผนการเรียน, เลือกห้องเรียนกายภาพได้หลายห้อง (ค้นหา + กรองตามความจุ), มีคำแนะนำแผนจัดห้องสอบให้อัตโนมัติ, แสดงจำนวนผู้สอบที่จัดสรรแล้วต่อห้อง
- ตั้งค่า column นักเรียน → เอาไว้กรอกตอน admission หรือเพิ่มนักเรียนเข้าโรงเรียน — เพิ่ม/ลบ/ซ่อน/เลื่อนลำดับ/ตั้งเป็นคอลัมน์หลักได้ พร้อมผูกกับฟิลด์ข้อมูลและเลือกการจัดวางข้อความ, มีปุ่มคืนค่าเริ่มต้น, คอลัมน์ระบบแก้ได้เฉพาะชื่อที่แสดง

### หน้าการรับสมัคร

จะแบ่งหน้าด้วยสถานะ คือถ้าอยุ่ที่เฟสไหนชื่อจะย้ายไปเฟสนั้น

- เฟสที่ 1 รับสมัครและคัดเลือก
    - ชื่อเด็กทุกคนที่สมัครจะต้องอยุ่ที่นี่
- เฟสที่ 2 ประกาศผลสอบ
    - ใครที่ผ่านการสอบแล้วจะโดนย้ายชื่อมาไว้หน้านี้
- เฟสที่ 3 รายงานตัวและมอบตัว
    - คนที่มีสิทธิ์มอบตัวจะโดนย้ายชื่อมาไว้หน้านี้

ฟีเจอร์ของหน้านี้:

- แท็บ roadmap ทั้ง 3 เฟส พร้อมแถบความคืบหน้า สลับเฟสแล้วล้างการเลือกทั้งหมด
- ค้นหาชื่อ/รหัสผู้สมัคร + กรองระดับชั้น + กรองแผนการเรียน + ปุ่มรีเซ็ตข้อมูล demo
- คอลัมน์ตารางเปลี่ยนไปตามเฟส (เอกสาร / ห้องสอบ-ที่นั่ง / ห้องเรียน / คะแนน-GPA)
- เปลี่ยนสถานะรายคนผ่าน dropdown พร้อม modal ยืนยันที่บอกว่าจะถูกย้ายไปแท็บไหน
- เมนู action รายแถวเปลี่ยนไปตามเฟส: ดูโปรไฟล์ / ดูเอกสารที่อัปโหลด / แก้ไขข้อมูล / พิมพ์ใบสมัคร / ลบ / กรอก-แก้ไขคะแนนสอบ / ส่งอีเมลแจ้งผลเดี่ยว / พิมพ์ใบมอบตัว / ตรวจสอบประวัติการเงิน
- เลือกได้หลายรายการ รวมถึงกด Shift ค้างแล้วคลิกเพื่อเลือกเป็นช่วง
- แถบ bulk action: เปลี่ยนสถานะพร้อมกันหลายคน / ส่งอีเมล / พิมพ์
- ปุ่มย้อนกลับ (Undo) บนข้อความแจ้งเตือนหลังเปลี่ยนสถานะ ทั้งแบบรายคนและรายกลุ่ม
- โมดัลกรอก/แก้ไขคะแนนสอบ (คะแนนดิบ + GPAX) และโมดัลดูเอกสารแนบ
- พิมพ์เอกสาร 3 แบบ (ใบสมัครและแสดงความจำนง / ใบแจ้งยอดและหลักฐานการจ่ายเงินค่าสอบ / ใบมอบตัวและข้อมูลห้องเรียน) พร้อมพรีวิวขนาด A4 ก่อนพิมพ์จริง

### หน้าสมัครเรียนออนไลน์ (ฝั่งผู้สมัคร/ผู้ปกครอง)

- ฟอร์มสมัคร 6 ขั้นตอนพร้อมแถบแสดงขั้นตอน: ข้อมูลส่วนตัว → ที่อยู่ → ข้อมูลครอบครัว (แยก 3 ขั้นย่อย: บิดา, มารดา, ผู้ปกครองหลัก) → ข้อมูลสถานศึกษาเดิม → ข้อมูลสุขภาพ → อัปโหลดเอกสารประกอบ 4 รายการ
- เลือกแผนการเรียนได้ 2 อันดับ
- เลขบัตรประจำตัวประชาชน 13 หลัก พร้อมปุ่มซ่อน/แสดงตัวเลข
- ปุ่มคัดลอกที่อยู่อัตโนมัติ (จากนักเรียนไปผู้ปกครอง, จากบิดาไปมารดา)
- ตรวจความครบถ้วนของข้อมูลก่อนไปขั้นถัดไปในแต่ละขั้นตอน
- เมื่อส่งใบสมัครสำเร็จ ออกรหัสใบสมัครให้อัตโนมัติ พร้อมโมดัลยืนยันการสมัคร

### หน้าตรวจสอบสถานะผู้สมัคร (ฝั่งผู้สมัคร/ผู้ปกครอง)

- ค้นหาด้วยเลขบัตรประจำตัวประชาชนหรือรหัสใบสมัคร
- ไทม์ไลน์แสดงความคืบหน้า 4 ขั้น
- การ์ดแสดงผลตามสถานะ 6 แบบ (ยังไม่ชำระเงิน / รอประกาศผล / สอบผ่าน / สำรอง / ไม่ผ่าน / มอบตัวแล้ว)
- QR PromptPay สำหรับชำระค่าสมัครสอบ
- แสดงห้องสอบ, เลขที่นั่งสอบ, กำหนดการสอบ
- แสดงคะแนนสอบและ GPAX เมื่อประกาศผลแล้ว
- ยืนยันรายงานตัวและมอบตัวออนไลน์ได้จากหน้านี้เลย
- พิมพ์ใบเสร็จค่าสมัคร / หลักฐานการมอบตัว

### หน้าส่งอีเมลแจ้งเตือนผู้ปกครอง

- รับรายชื่อผู้รับต่อมาจากหน้าอื่น (เช่น เลือกจากตารางแล้วกดส่งอีเมล)
- เทมเพลตสำเร็จรูป 4 แบบ: แจ้งผลสอบผ่าน, แจ้งผลสอบไม่ผ่าน, แจ้งเอกสารไม่ครบ, แจ้งชำระค่าสมัคร
- แท็บ placeholder 4 ตัวสำหรับแทรกลงเนื้อหาอีเมล
- แก้ไขหัวข้อและเนื้อหาอีเมลได้อิสระ
- แผงแสดงรายชื่อผู้รับพร้อมข้อมูลประกอบ
- แนบไฟล์ได้
- มีหมายเหตุอ้างอิงมาตรฐาน PDPA กำกับไว้

### หน้าโปรไฟล์และแก้ไขข้อมูลรายบุคคล

- หน้าโปรไฟล์ (อ่านอย่างเดียว): การ์ดสรุปข้อมูล, ไทม์ไลน์ 6 ขั้นของกระบวนการคัดเลือก, แบ่งเป็น 4 แท็บ (ประวัติ+ที่อยู่ / ครอบครัวผู้ปกครอง / การศึกษา+สุขภาพ / หลักฐานใบสมัคร), ปุ่มพิมพ์เอกสารพร้อมพรีวิว A4
- หน้าแก้ไขข้อมูล: แบ่งเป็น 3 ส่วน (ข้อมูลส่วนตัว / ข้อมูลติดต่อและผู้ปกครอง / แผนการศึกษา), ปิดบังเลขบัตรประชาชนไว้เป็นค่าเริ่มต้น, มีแถบแสดงสถานะใบสมัครและผู้แก้ไขข้อมูลล่าสุดกำกับ

### ขอบเขตข้อมูลและสถานะ

หัวข้อนี้ไม่ใช่ฟีเจอร์ที่กดใช้ได้ในหน้าไหนหน้าหนึ่ง แต่เป็นคำศัพท์และตัวเลขกลางที่ทุกหน้าด้านบนอ้างอิงถึงร่วมกัน (เช่น "สถานะ 6 แบบ" ในหน้าตรวจสอบสถานะ หรือ "ชิปกรองสถานะ" ในหน้าข้อมูลนักเรียน ก็มาจากชุดสถานะเดียวกันที่ลิสต์ไว้ด้านล่างนี้) เลยแยกเขียนไว้ท้ายเอกสารแทนที่จะผูกกับหน้าใดหน้าหนึ่ง

#### สถานะของผู้สมัคร/นักเรียน

รวมทั้งหมด 14 สถานะ แบ่งเป็นช่วงกระบวนการรับสมัคร 9 สถานะ + หลังมอบตัวอีก 5 สถานะ

- เฟสที่ 1 รับสมัครและคัดเลือก: ยังไม่ได้ชำระเงินค่าสอบ, ชำระเงินค่าสอบแล้ว
- เฟสที่ 2 ประกาศผลสอบ: รอประกาศผลสอบ, สอบผ่าน, สำรอง, สอบไม่ผ่าน
- เฟสที่ 3 รายงานตัวและมอบตัว: ยังไม่ได้รายงานตัว, รายงานตัวแล้ว, กำลังศึกษา / มอบตัวเสร็จสิ้น
- หลังมอบตัว (ไม่อยู่ในเฟสไหนแล้ว): สำเร็จการศึกษา, ลาออก, ย้ายโรงเรียน, พ้นสภาพ, พักการเรียน

สถานะ "กำลังศึกษา / มอบตัวเสร็จสิ้น" คือจุดเชื่อมระหว่าง 2 ฝั่งของระบบ — จบเฟส 3 ของฝั่งรับสมัครแล้ว กลายเป็นสถานะตั้งต้นของฝั่งทะเบียนนักเรียน ส่วน 5 สถานะหลังมอบตัวเป็นของหน้าข้อมูลนักเรียนใช้กรองต่อ (เช่นกรองหาคนที่ลาออกไปแล้ว)

#### รหัสประจำตัว

- รหัสใบสมัคร รูปแบบ `APP-ปีการศึกษา-ลำดับ` ออกให้อัตโนมัติตอนส่งใบสมัครสำเร็จ
- รหัสนักเรียน รูปแบบ `STD-ปีการศึกษา-ลำดับ` ออกให้อัตโนมัติตอนมอบตัวเสร็จสิ้นเท่านั้น (ก่อนหน้านั้นยังไม่มีรหัสนี้)

#### โครงห้องเรียน

- รองรับระดับชั้น ม.1-ม.6 ระดับชั้นละ 5 ห้อง รวม 30 ห้องเรียนทั้งโรงเรียน
- ใช้เป็นฐานเดียวกันของชิปกรองห้องเรียน, โมดัลย้ายห้องเรียน, โมดัลเลื่อนชั้น ไม่ได้แยกกำหนดคนละที่

#### ที่เก็บข้อมูลและข้อมูลตัวอย่าง

- เก็บข้อมูลไว้ใน LocalStorage ของเบราว์เซอร์ แยกเป็น 5 ชุด: ข้อมูลผู้สมัคร/นักเรียน, ตั้งค่าฟิลด์ฟอร์มรับสมัคร, แผนหลักสูตร, ห้องสอบ, คอลัมน์ตารางนักเรียน (แต่ละหน้าตั้งค่าคุมชุดข้อมูลของตัวเอง)
- มีข้อมูลตัวอย่าง (mock data) ฝังไว้ในระบบให้เล่นได้ทันทีโดยไม่ต้องกรอกเอง: นักเรียน/ผู้สมัครรวม 119 คน (ในจำนวนนี้ 108 คนสถานะกำลังศึกษา กระจายเต็มทั้ง 30 ห้องเรียน), แผนการเรียน 5 แผน, ห้องเรียนกายภาพ 9 ห้อง

## ส่วนที่แคร์ทำ

ฝั่งนี้คือบุคลากร/อาจารย์, ระบบการลา (ทั้งของครูและของนักเรียน), บัตรขออนุญาต และตั้งค่าระบบ — คนละฝั่งกับทะเบียนนักเรียนของเนยสด

### หน้าแดชบอร์ดภาพรวม

- การ์ดสรุป 4 ตัว: บุคลากรทั้งหมด / ใบลารออนุมัติ / เอกสารใกล้หมดอายุ / อนุมัติแล้ววันนี้
- รายการคำขอลาล่าสุด พร้อมลิงก์ไปหน้าอนุมัติ
- แผงการแจ้งเตือนสำคัญ (ใบประกอบวิชาชีพใกล้หมดอายุ, ใบลาค้างอนุมัติ, Visa/Work Permit หมดอายุ)
- ทางลัดด่วน 6 ปุ่มไปยังงานที่ใช้บ่อย

### หน้าข้อมูลบุคลากรและอาจารย์

- รายชื่อบุคลากรพร้อมค้นหา (ชื่อ, รหัสบุคลากร, ตำแหน่ง, กลุ่มสาระฯ) และกรองสถานะความครบถ้วนของข้อมูล
- การ์ดสรุป 3 ตัว: บุคลากรทั้งหมด / รอตรวจสอบเอกสารไม่ครบ / ข้อมูลครบถ้วนสมบูรณ์
- เพิ่มบุคลากรรายบุคคล, แก้ไข, ลบออกจากระบบ
- ฟอร์มแก้ไขแบ่ง 3 กลุ่ม 11 แท็บ
    - ข้อมูลพื้นฐาน: ประวัติส่วนตัว, ที่อยู่ตามทะเบียนบ้าน, ที่อยู่ติดต่อได้, ข้อมูลครอบครัว
    - การศึกษา & อบรม: ข้อมูลการศึกษา, ข้อมูลเกียรติคุณ, ประวัติอบรม ดูงาน, คะแนน TOEIC
    - ตำแหน่ง & ใบประกอบฯ: ข้อมูลตำแหน่งงาน, ใบอนุญาตประกอบวิชาชีพ, ประวัติรับเครื่องราชฯ
- ที่อยู่เลือกแบบ จังหวัด → อำเภอ → ตำบล แล้วเติมรหัสไปรษณีย์ให้เอง + ติ๊กใช้ที่อยู่เดียวกับทะเบียนบ้าน
- ฟิลด์แบบเพิ่มได้หลายรายการ: บุตร/ธิดา, รางวัลและเกียรติคุณ, ประวัติอบรม, เครื่องราชอิสริยาภรณ์
- ตรวจความถูกต้อง: เลขบัตรประชาชน 13 หลัก, เบอร์โทร 10 หลัก, วันเกิดต้องไม่เกินวันปัจจุบัน

### หน้านำเข้าข้อมูลบุคลากร

- ดาวน์โหลดเทมเพลต Excel พร้อมหัวคอลัมน์ภาษาไทยและแถวตัวอย่าง
- อัปโหลดไฟล์ Excel/CSV แบบลากวาง อ่านไฟล์จริงและจับคู่หัวคอลัมน์ภาษาไทยให้อัตโนมัติ
- แปลงปี พ.ศ. เป็น ค.ศ. ให้เอง
- ตรวจข้อมูลรายแถวก่อนนำเข้า พบข้อผิดพลาดจะแจ้งเป็นรายบรรทัดและหยุดการนำเข้าไว้ก่อน
- ตารางพรีวิวผลวิเคราะห์ก่อนกดยืนยัน แล้วนำเข้าแบบเพิ่มใหม่/อัปเดตทับตามรหัสบุคลากร
- อัปโหลดรูปประจำตัวแบบจับคู่ชื่อไฟล์กับรหัสบุคลากร

### หน้าพิมพ์เอกสาร & QR Studio

- สร้าง QR Code ของ LINE Official Account ประจำโรงเรียน
- พรีวิวแฟ้มประวัติประจำตัวขนาด A4 สร้างจากข้อมูลจริงของบุคลากรที่เลือก แบ่ง 4 ส่วน (ประวัติส่วนบุคคล / การศึกษาและเกียรติคุณ / ตำแหน่งและใบประกอบวิชาชีพ / ฝึกอบรมและเครื่องราชฯ)
- สั่งพิมพ์ประวัติรายคน / พิมพ์ทั้งหมด / Export เป็นรูปภาพ / ดาวน์โหลด QR

### หน้าระบบการลาของบุคลากร

- ตั้งค่าการลา 6 ขั้นตอน ทุกขั้นมีพรีวิวสดข้าง ๆ
    - ตัดรอบปีทำงาน → กำหนดผู้อนุมัติ (เพิ่ม/ลบรายชื่อได้) → ตั้งโควตาลาปี (ลาป่วย/ลาพักผ่อน-ลากิจ/ลาคลอดบุตร) → เงื่อนไขการลา (ลาครึ่งวัน, บังคับใบรับรองแพทย์, ทบยอดวันลาสะสม) → จำนวนวันล่วงหน้าและการเตือนเอกสารหมดอายุ → ผู้มีสิทธิ์รับการแจ้งเตือน
- ยื่นคำขอลา
    - การ์ดโควตาคงเหลือรายประเภท
    - เลือกลาทั้งวัน / ครึ่งเช้า / ครึ่งบ่าย
    - คำนวณวันลาสุทธิให้อัตโนมัติ หักเสาร์-อาทิตย์และวันหยุดนักขัตฤกษ์
    - แนบไฟล์หลักฐานแบบลากวาง จำกัดขนาด 5MB
    - เตือนเมื่อต้องแนบใบรับรองแพทย์ และเตือนเมื่อยื่นล่วงหน้าไม่พอ
    - สรุปทวนรายละเอียดก่อนยืนยันส่ง
    - แก้ไขใบลาที่ยังไม่ผ่านการพิจารณาได้
    - ตารางประวัติการลาของตัวเอง พร้อมกรองตามสถานะ
- อนุมัติการลา (เฉพาะสิทธิ์หัวหน้าครู)
    - ปฏิทินภาพรวมการลาของบุคลากร สลับมุมมองรายเดือน/รายสัปดาห์/รายวัน แสดงวันหยุดนักขัตฤกษ์ และกดดูรายชื่อผู้ลาในแต่ละวันได้
    - ตารางคำขอพร้อมกรองสถานะ เรียงรายการที่รออนุมัติขึ้นก่อน
    - อนุมัติ/ไม่อนุมัติพร้อมบังคับใส่เหตุผล และตัดโควตาวันลาให้อัตโนมัติเมื่ออนุมัติ
    - เปลี่ยนสถานะย้อนหลังได้ พร้อมคืนโควตาให้
    - ดูรายละเอียดคำขอรายใบ
- สลับบทบาทผู้ใช้ระหว่างคุณครูทั่วไป (ผู้ยื่นขอลา) กับหัวหน้าครู (ผู้อนุมัติ)

### หน้าบัตรขออนุญาตของนักเรียน

- ยื่นบัตรขออนุญาต 3 ขั้นตอน: ค้นหานักเรียน → เลือกประเภท → กรอกรายละเอียด
    - ประเภทบัตร: เข้าห้องเรียนช้า, ออกนอกห้องเรียน, ออกนอกบริเวณโรงเรียน, อนุญาตอื่น ๆ, ผู้ปกครองมารับก่อนกำหนด, มอบหมายเวร
    - พรีวิวบัตรสดพร้อมเลขที่ใบอนุญาตและช่องลงนาม 3 ช่อง (ผู้ขออนุญาต / ครูที่ปรึกษา / ผู้อนุมัติ)
    - บันทึก / พิมพ์บัตร / ทำรายการใหม่
- รายการบัตรขออนุญาตของนักเรียน
    - ปฏิทินภาพรวมรายเดือน/สัปดาห์/วัน กดดูรายชื่อรายวันได้
    - ตารางพร้อมค้นหาและกรองประเภท/ชั้นปี/ห้อง/สถานะ
    - อนุมัติ/ไม่อนุมัติพร้อมบังคับใส่เหตุผล, เปลี่ยนสถานะย้อนหลัง, แก้ไขรายการที่ยังรอตรวจสอบ
    - Export เป็น Excel
- ประวัติรายบุคคล: สถิติการขออนุญาตสะสมรายประเภท + รายงานการตัดคะแนนความประพฤติ พร้อมสั่งพิมพ์
- สรุปรวมตามชั้นเรียน: ตารางไขว้ชั้นเรียน × ประเภทบัตร กรองตามปีการศึกษา/เดือน/ชั้น พร้อม Export Excel

### หน้าการลาเรียนของนักเรียน

- ยื่นขอลา 3 ขั้นตอน: ค้นหานักเรียน → เลือกประเภทการลา → กรอกรายละเอียด
    - พรีวิวใบลาสดพร้อมเลขที่ใบลาและช่องลงนาม
    - พิมพ์แบบฟอร์มใบลาแบบหนังสือราชการ (เรียน ผู้อำนวยการ, ที่อยู่ติดต่อระหว่างลา, ช่องลงชื่อ)
- อนุมัติการลานักเรียน
    - ปฏิทินภาพรวมรายเดือน/สัปดาห์/วัน พร้อมวันหยุดนักขัตฤกษ์ และกดดูรายชื่อผู้ลารายวัน
    - ตารางคำขอพร้อมค้นหาและกรองประเภท/ชั้นปี/ห้อง/สถานะ + Export Excel
    - อนุมัติ/ไม่อนุมัติพร้อมบังคับใส่เหตุผล, เปลี่ยนสถานะย้อนหลัง, ดูรายละเอียดรายใบ, พิมพ์ใบลา
    - ประวัติการลารายบุคคล พร้อมการ์ดโควตาวันลาคงเหลือรายประเภท
- ตั้งค่าการลาเรียน 5 ขั้นตอน พร้อมพรีวิวสดทุกขั้น
    - ปีการศึกษาและช่วงภาคเรียน → ประเภทการลา (เพิ่ม/แก้ไข/ลบ พร้อมกำหนดสีป้าย) → ลำดับขั้นผู้ตรวจสอบ/อนุมัติ → โควตาวันลารายประเภท → เงื่อนไขและการแจ้งเตือนเพิ่มเติม
    - บันทึกโดยระบุวันที่มีผลบังคับใช้ ตั้งล่วงหน้าได้
    - ประวัติเวอร์ชันการตั้งค่า แยกสถานะใช้งานอยู่ / รอมีผลในอนาคต / ในอดีต พร้อมกดดูรายละเอียดย้อนหลัง

### หน้าตั้งค่าระบบ

- การตั้งค่าทั่วไป: ข้อมูลโรงเรียน (ชื่อไทย/อังกฤษ, รหัสโรงเรียน, เบอร์โทร, ที่อยู่), ปีการศึกษาปัจจุบันและวันเปิด-ปิดเทอม, ตั้งค่าการแจ้งเตือนระบบ
- วันเวลาเข้าออก: เวลาเข้า-เลิกงาน, เวลาพักกลางวัน, เกณฑ์นาทีที่ถือว่ามาสาย/กลับก่อน, เวลาเริ่มนับ OT, เลือกวันทำงานประจำสัปดาห์, จัดการกะพิเศษ (เพิ่ม/แก้ไข/ลบ), จัดการวันหยุดนักขัตฤกษ์และวันหยุดพิเศษ (เพิ่ม/ลบ)
- สิทธิ์ผู้ใช้งาน: ตารางสิทธิ์การเข้าถึงตามบทบาท (ผอ. / รองผอ. / ผู้ดูแลระบบ / ครู) แยกตามโมดูล, การ์ดนับจำนวนผู้ใช้แต่ละบทบาท, ตารางจัดการบทบาทรายบุคคลพร้อมค้นหาและกรอง
- ผู้ลงนามเอกสาร: รายชื่อผู้ลงนามพร้อมลำดับการลงนาม (เพิ่ม/แก้ไข/ลบ) และกำหนดผู้ลงนามแยกตามประเภทเอกสาร (ใบอนุมัติการลา, หนังสือรับรองการเป็นบุคลากร, หนังสือรับรองเงินเดือน, หนังสือขอความอนุเคราะห์)

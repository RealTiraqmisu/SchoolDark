## 2. `admission/` — ที่เหลือยังไม่ได้แก้ (a11y / dead code / ดีไซน์)

> ส่วนใหญ่ในหัวข้อนี้แก้แล้วในรอบ 2026-09-29 ดูสรุปที่ "สิ่งที่แก้ไปแล้วรอบใหม่ (2026-09-29)" ด้านบน —

- **a11y**: โมดัลทั้งหมดเป็น `div.fixed.hidden` ธรรมดา ไม่มี `role="dialog"`/focus trap/Esc, ปุ่มไอคอน
  ล้วนส่วนใหญ่ไม่มี `aria-label`, dropdown ไม่มี `aria-expanded`, ใช้ `alert()`/`window.confirm()`
  เกือบทุกจุด (ต่างจาก `parent/` ที่มี `ParentUI.createDialog`/`ParentUI.confirm` แล้ว)
- **ฟอร์ม**: ไม่มี `autocomplete`/`inputmode` เลยทั้งโฟลเดอร์, `apply.html`/`edit.html` ไม่มี
  `required`, เช็คเลขบัตรแค่ความยาว
- **คอนทราสต์สี**: `text-slate-400` (~2.6:1) ใช้เป็นตัวหนังสือจริงหลายร้อยจุด (`students.html` ×72,
  `profile.html` ×65, `index.html` ×61)
- **class ที่ไม่มีจริงใน Tailwind**: `h-4.5`/`w-4.5`/`p-4.5` (~40 จุด, ไอคอนเรนเดอร์ 24px แทนที่จะเป็น
  18px ที่ตั้งใจ), `text-slate-650`, `text-slate-955` (พบใหม่ระหว่างแก้รอบนี้ที่ `profile.html:787`,
  ไม่ได้แก้เพราะไม่อยู่ในสโคป escapeHtml — ยังคงเป็น bug ค้างอยู่)
- **โค้ดตาย**: `admission/materials/uxui-from-care/` ~16,000 บรรทัด เป็นสำเนาเก่าของ `schooldark/`
  ทิ้งไว้เฉย ๆ ไม่ได้ใช้งาน
- **ข้อมูลแผนการเรียนไม่ตรงกัน 4 ที่**: static list ใน `store.js`, course plans (settings), chip
  ใน `students.html`, hardcoded options ใน `index.html` — `edit.html` แก้ให้ใช้ dynamic list แล้ว
  รอบนี้ แต่อีก 3 จุดยังไม่ได้รวมเป็นแหล่งเดียว
- หน้า public (`apply.html`/`status.html`) ยังโหลด sidebar แอดมินเต็มรูปแบบ + ปุ่ม "fill mock" ของ
  staff โผล่ในฟอร์มสาธารณะ
- Mobile: sidebar กว้างคงที่ 72px แม้จอเล็ก ไม่มีโหมด off-canvas
- `tailwind.config` ก้อนเดียวกัน copy-paste อยู่ทุกหน้า (11 ไฟล์), `showToast`/`openModal`/
  `getBadgeClass`/`maskCid` ก็ copy ซ้ำหลายไฟล์เช่นกัน

## 4. ส่งต่อให้ care — `schooldark/` สาเหตุแลคที่ยังไม่ได้แก้

แก้แล้วรอบนี้ (ปลอดภัย ไม่กระทบ JS): `.modal-overlay` เอา backdrop-filter ออกตอนปิด + ลบ Font Awesome
CDN ที่ไม่มีใครใช้ ที่เหลือด้านล่างเป็นของ care ตัดสินใจเอง เพราะต้องแก้ JS/โครงสร้างข้อมูล:

1. **xlsx.js (~900KB) และ Chart.js โหลดแบบ synchronous ใน `<head>`** ของ `app.html`/
   `leave-features.html` — บล็อกการโหลดหน้าทั้งที่ใช้เฉพาะตอนกด export/เปิดแดชบอร์ด ควรโหลดแบบ lazy
   ตอนกดปุ่มแทน
2. **`@import` Google Fonts ใน `app.css`** — เป็น chained request บล็อก render เพิ่ม ควรเปลี่ยนเป็น
   `<link rel="preconnect">` + `<link>` ตรง ๆ (แบบที่ `admission/` ทำ)
3. **`renderStudentDashboard()`/`sdCompute()` ใน `leave-features.html`** คำนวณ `getAttendance()`
   ประมาณ 35,000 ครั้งต่อการเปลี่ยนตัวกรองช่วงเวลา (175 นักเรียน × ~100 วัน × 2 ช่วงเทียบ) แต่ละครั้ง
   มี linear scan + `new Date()` + hash คำนวณสุ่ม ควร cache ผลตาม (ช่วงวัน, ห้อง) แทนคำนวณใหม่ทุกครั้ง
4. **ช่องค้นหาไม่มี debounce** — `renderAttendanceReport()`/ตารางอื่น ๆ คำนวณใหม่ทุกตัวอักษรที่พิมพ์
   (บางช่องมีนักเรียนหลายพันแถวให้กรอง)
5. Chart.js ยังเปิด animation ค่า default (`responsive: true` ไม่ปิด `animation:false`) ทำลายเฟรมตอน
   สร้าง/ทำลายกราฟใหม่
6. `.glass-card` มี `box-shadow` ใหญ่ + transition ตอน hover (41 จุดใน `app.html`, 26 จุดใน
   `leave-features.html`) — เมาส์วิ่งผ่านการ์ดหลายใบพร้อมกันจะ repaint ถี่
7. **navigate ซ้ำตอนโหลด `app.html`**: `app.js` เรียก `navigate('dashboard', ...)` แล้ว
   `settings.js` เรียก `navigateToView("general")` ทับอีกที (เพราะ listener ผูกทีหลัง) น่าจะทำให้
   เปิดมาแล้วเจอหน้า "ตั้งค่า → ทั่วไป" แทนที่จะเป็นแดชบอร์ด — ไม่ใช่ปัญหาความเร็วแต่เป็นบั๊ก UX ที่เจอ
   ระหว่างสแกน
